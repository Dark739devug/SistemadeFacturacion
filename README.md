# 📊 API Certificador de Facturación Electrónica

---

## ✨ Descripción

Bienvenido al repositorio del **API Certificador de Facturación Electrónica**.  
Este proyecto gestiona la certificación de facturas electrónicas, administración de establecimientos, series de facturación, usuarios y estadísticas de manera eficiente, usando **Spring Boot** en el backend y **React** en el frontend.

---

## 🛠️ Tecnologías utilizadas

| Componente | Tecnologías |
| :--- | :--- |
| **Backend / API** | Spring Boot, REST, Maven |
| **Frontend** | React.js |
| **Base de datos** | PostgreSQL |
| **Autenticación** | JWT (JSON Web Tokens) |
| **Control de versiones** | Git & GitHub |

---

## 🌟 Características principales

- 📑 Gestión completa de **facturas certificadas** (creación, edición, cancelación).  
- 👥 Administración de **clientes y usuarios** con roles y permisos.  
- 🏢 Gestión de **establecimientos certificados**.  
- 📦 Control de **series y correlativos** de facturación.  
- 📈 Reportes y **estadísticas diarias** de transacciones y facturación.  
- 🔐 Autenticación segura con **JWT**.  
- 📝 Registro de **logs del sistema** y auditoría de transacciones.
